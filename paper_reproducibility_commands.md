### 3.3 Constrained label-wise vote thresholds

The main experiment did not choose thresholds directly on the test set. The three members first generated predictions on the validation split. For each label, thresholds of 1/3, 2/3, and 3/3 votes were compared under a precision-drop constraint relative to 2/3 majority voting. The maximum allowed precision drop was 0.03 for ordinary labels, 0.15 for `oxidizing` and `gas_under_pressure`, and 0.12 for `cmr`. Eligible candidates were ranked first by validation F1 and then by recall. The selected thresholds were frozen before application to the test set. Neither the test set nor the external test set may participate in threshold selection.

```bash
python calibrate_multilabel_vote_thresholds.py \
  --val-gold sft_coarse_jsonl_seed123_ghs_pictograms_rare2x/val.jsonl \
  --test-gold sft_coarse_jsonl_seed123_ghs_pictograms_rare2x/test.jsonl \
  --val-pred \
    predictions/mistral_main_trainseed123_val_predictions.jsonl \
    predictions/mistral_main_trainseed777_val_predictions.jsonl \
    predictions/mistral_main_trainseed2025_val_predictions.jsonl \
  --test-pred \
    predictions/mistral_main_trainseed123_predictions.jsonl \
    predictions/mistral_main_trainseed777_predictions.jsonl \
    predictions/mistral_main_trainseed2025_predictions.jsonl \
  --output-dir predictions \
  --prefix mistral_split123_ghs_pictograms_rare2x_labelcal

python evaluate_pubchem_coarse_predictions.py \
  --gold sft_coarse_jsonl_seed123_ghs_pictograms_rare2x/test.jsonl \
  --pred predictions/mistral_split123_ghs_pictograms_rare2x_labelcal_constrained_ensemble3_predictions.jsonl \
  --output-dir evaluation_llm_coarse/mistral_split123_ghs_pictograms_rare2x_labelcal_constrained_ensemble3 \
  --prefix mistral_split123_ghs_pictograms_rare2x_labelcal_constrained_ensemble3
```

The script outputs both `rareonly` and `constrained` results and saves a JSON audit of validation-based threshold selection. The reported main result uses the constrained version. Confirm that the output label-wise thresholds match the recorded experiment. Verification targets are Micro-Precision 0.7569, Micro-Recall 0.7739, Micro-F1 0.7653, and Macro-F1 0.7852.
